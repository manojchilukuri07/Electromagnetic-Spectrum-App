# 🌈 Electromagnetic Spectrum Educational App

An interactive educational web application built using Python and Streamlit to help students understand the electromagnetic spectrum.

## 🎯 Project Objective

The main objective of this project is to provide an interactive and easy-to-understand platform for learning about electromagnetic waves, their properties, applications, and relationships between wavelength, frequency, and energy.

## ✨ Features

- 🌈 Interactive Electromagnetic Spectrum
- 🔬 Explore seven EM spectrum regions
- 🌈 Visible Light section
- 🌊 Wave diagrams
- 📊 Spectrum comparison
- 📈 Wavelength-frequency-energy relationships
- 🧮 Wave calculator
- 📝 Interactive quiz
- 📊 Learning progress tracking
- ℹ️ Project information

## 📚 Electromagnetic Spectrum Regions

The application covers:

1. Radio Waves
2. Microwaves
3. Infrared
4. Visible Light
5. Ultraviolet
6. X-rays
7. Gamma Rays

## 🧮 Mathematical Concepts

### Speed of Light

c = fλ

Where:

- c = speed of light
- f = frequency
- λ = wavelength

### Photon Energy

E = hf

Where:

- E = photon energy
- h = Planck's constant
- f = frequency
